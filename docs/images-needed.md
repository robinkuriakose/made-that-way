# Images

The list of images still wanted, with the file name for each and what it should show, lives beside the images themselves: [images/IMAGES-NEEDED.md](../images/IMAGES-NEEDED.md).

Name each file with the question id (for example `plane-ashtray.jpg`) and drop it in `images/`. `npm run images` makes the published WebP and a thumbnail in `public/images/`.

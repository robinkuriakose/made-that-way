# Images needed

Updated 1 October 2026. Most of the earlier list is done (ticked below). **Wanted now: pictures for the 20 newest questions**, then whatever is still unticked. Hard questions are optional.

## How to send them

1. **Name each file with the question id**, e.g. `plane-ashtray.jpg`, exactly as written in the tables below. Any format is fine: JPG, PNG, WebP, HEIC. (A file with another name, like `kadokeshi-eraser.jpg`, can't be matched to its question.)
2. **Drop it in this folder** (`images/`).
3. Tell me. I publish them and attach each one to its question.

**Show the detail clearly.** Close up, well lit, the thing the question asks about in plain view. A picture that hints at the answer is fine.

Also good to know:
- **Crop close:** the frame is short and wide, so a close-up of the detail beats a pretty wide shot.
- **Rights:** only use your own photos, public domain, or licensed images. Note the source for each so it can get a credit line.

Every table gives the question and its right answer beside the file name, so you can see what the picture is for. The question wording is what players see today.

Tiers: **E** easy, **M** medium, **H** hard. These are my proposed tags, waiting for your OK.
